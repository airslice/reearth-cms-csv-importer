# User Persona

## User

**Role**: CSV Data Importer

**Goal**: Successfully import CSV data into Re:Earth CMS with correct field mappings and minimal errors

**Context**: Anyone with a Re:Earth CMS API key who needs to import CSV data - no specific role or authentication required. The tool is used directly by anyone needing to load CSV data into their Re:Earth CMS instance.

**Characteristics**:
- Has a Re:Earth CMS API key and workspace ID
- Needs to import CSV data (occasional or frequent use)
- May create new data models or import to existing models
- Expects clear guidance and error feedback during the import process
